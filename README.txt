READY VALLEY 2029 WEBSITE

Files
- index.html: page structure and title
- styles.css: readable, standard CSS and responsive theme
- script.js: page rendering, charts, search, filters, navigation, and print control
- proposal-data.json: proposal text, project figures, references, and schedule data
- assets/aistudio/: proposal PDF asset

To view locally, open this folder in Visual Studio Code and launch index.html with the Live Server extension. The proposal data is loaded as a local JSON file, so use a local web server rather than opening index.html directly from Finder.
